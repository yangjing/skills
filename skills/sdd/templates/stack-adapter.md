## 0. Agent 执行协议

1. **Trigger**：项目使用 `<技术栈>`，且命中 `<被适配分册>` 的 `<章节范围>` 时，MUST 与该章节一并加载本文。
2. **Load**：只读与已命中 references 章节对应的节；MUST NOT 预读全文。
3. **Apply**：职责边界与硬要求以 `references/` 为准，**本层只覆盖 API 与配置的具体形态**。
4. **Conflict / Stop**：本层与 `references/` 原则冲突时，MUST 以 `references/` 为准并报告本层需要修订；项目实际实现与本层冲突时，MUST 以实现为事实并停止报告。
5. **Output**：交付说明 MUST 点名依据的适配节号与跑过的门禁。
6. **MUST NOT**：MUST NOT 把本文条款当作其它技术栈的依据。
